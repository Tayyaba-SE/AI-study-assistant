Object-Oriented Programming (OOP) is a programming paradigm based on the concept of “objects”, which can contain data in the form of fields (attributes) and code in the form of procedures (methods). OOP helps in structuring a program so that properties and behaviors are bundled into individual objects.

The four main pillars of OOP are:

  1. 1

    Encapsulation – Bundling data and methods that operate on the data within one unit (class).

  2. 2

    Abstraction – Hiding complex implementation details and showing only the essential features.

  3. 3

    Inheritance – Creating new classes from existing classes to reuse code and extend functionality.

  4. 4

    Polymorphism – The ability of an object to take many forms.

These principles make code more modular, reusable, and easier to maintain.
